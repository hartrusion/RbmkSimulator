# Glossary

This glossary explains the terms used in the LLM documentation of the project that go beyond basic technical knowledge. It was started on 2026-11-14 and only contains the terms of the work documented in LLM-HISTORY.md so far.

**Table 1**: Terms and abbreviations

| Term | Explanation |
|---|---|
| AbsoluteLayout | Layout manager of the NetBeans library org.netbeans.lib.awtextra, which places components at fixed coordinates given by AbsoluteConstraints. |
| Base size | Size of the content area of a panel at a scale factor of 1.0, from which ScaleableAbsoluteLayout calculates the zoom factor. |
| Design time | State in which a component runs inside the NetBeans GUI editor, signalled by java.beans.Beans.isDesignTime(). |
| GUI editor (NetBeans GUI Builder) | Visual form editor of NetBeans, which stores a form in a .form file and generates initComponents() from it. |
| LLM | Large language model; code generated by an LLM is marked as such. |
| Mnemonic panel | Panel of RbmkSimulator that shows a process diagram of a plant section and is displayed in an InternalFrameMnemonic. |
| Scale factor | Ratio of the available size to the base size, by which ScaleableAbsoluteLayout zooms positions, sizes, fonts and icons. |
