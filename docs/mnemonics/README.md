# Mnemonic Schematics

Mnemonic displays are inspired by the original displays found in the control 
rooms. They are very simplified (as the whole simulator is a simplification).

The svg files in this directory define the static background drawings of the 
mnemonic displays. They were drawn using Inkscape. Valves and pumps are not 
part of the drawings, they are generated by drawing onto the GUI with AWT 
commands directly.

The backgrounds are not used as images. Instead, `MnemonicSvgConverter.java` 
translates each svg file into a Java class that draws the same lines and 
shapes with Java2D. This keeps the drawings sharp when a mnemonic display is 
zoomed by resizing its window. The generated classes extend 
`MnemonicBackground` and are placed on the mnemonic panels like any other 
component.

To modify or update mnemonics, the svg can be modified with the hidden 
elements layer visible. Those help to position the JComponent elements in GUI 
builder exactly. Hidden layers and hidden elements are ignored by the 
converter. Afterwards, run the converter in this directory using only the JDK:

    java MnemonicSvgConverter.java

It converts all svg files in this directory and writes a file 
`<Name>Background.java` next to each svg file. The converter does not write 
into the project; copy the generated file into the package 
`com.hartrusion.rbmksim.gui.mnemonic` to replace the previous version.

The converter only supports what the drawings need: layers and groups 
(including transformations), paths with straight lines and cubic bezier 
curves, circles, ellipses, rectangles without rounded corners and arcs drawn 
with the Inkscape circle tool. Line caps, line joins and the miter limit are 
taken exactly as set in the svg. Colors must be one of the colors defined in 
`MnemonicColors`. Anything else, like text, transparency or dashed lines, 
aborts the conversion of that file with an error message.
